# CodeSpace — منصة تعليم البرمجة

## الملفات
كل ملفات المشروع موجودة في نفس المجلد الجذر لتسهيل رفعه مباشرة إلى GitHub.

- `index.html` — الصفحة الرئيسية والمنصة
- `style.css` — تنسيقات الموقع
- `app.js` — التفاعلات والتنقل وتسجيل الدخول التجريبي
- `lecture-01.jpg` — صورة المحاضرة الأولى
- `.nojekyll` — لتحسين الاستضافة على GitHub Pages

## تشغيل على GitHub Pages
1. ارفع جميع الملفات الموجودة في هذا المجلد إلى مستودع GitHub.
2. من Settings → Pages اختر النشر من فرع `main` ومجلد `/ (root)`.
3. افتح الرابط الذي يعطيه GitHub Pages.

> تسجيل الدخول في النسخة الحالية تجريبي ومحلي، وليس نظام حسابات حقيقي بقاعدة بيانات.
